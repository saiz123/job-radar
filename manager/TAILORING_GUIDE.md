# Tailoring Guide

## Goal
Increase relevance to a specific job without crossing into fiction.

## Allowed changes
- reorder bullet points to emphasize the most relevant true experience
- swap in more job-relevant phrasing when it is still factually accurate
- emphasize Wazuh, SIEM, log review, triage, NIST, Linux, Docker, and cloud/security lab work when the role values those
- tighten the summary toward the target title
- add a short cover letter that directly addresses fit and sponsorship honestly

## Not allowed
- invent production Splunk experience
- claim incident ownership beyond actual scope
- claim active clearance, citizenship, or unrestricted sponsorship status
- inflate volunteer work into leadership scope that did not happen
- add tools or duties Sai has not actually used

## Tailoring checklist
1. mirror the job title in the summary where truthful
2. map top 5-10 keywords from the posting to real resume evidence
3. remove or de-emphasize irrelevant content
4. preserve chronology and factual integrity
5. include sponsorship wording only when strategically necessary and honest

## Output package
For each tailored application create:
- `resume.md`
- `fit_notes.md`
- optional `cover_letter.md`

## `fit_notes.md` structure
- target role
- top matched requirements
- weak spots / risks
- exact changes made to the resume
- interview framing notes
