# Application Tracker

Primary tracker file:
- `state/applications.csv`

Columns:
- `created_at`
- `job_id`
- `company`
- `title`
- `link`
- `score`
- `status`
- `resume_path`
- `cover_letter_path`
- `notes`

Status suggestions:
- `shortlisted`
- `tailored`
- `applied`
- `skipped`
- `rejected`

If spreadsheet export is needed later, this CSV can be opened directly in Excel or converted into `.xlsx` once command execution is stable.
