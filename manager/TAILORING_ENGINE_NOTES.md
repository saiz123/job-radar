# Tailoring Engine Notes

The first version of the tailoring engine is conservative by design.

## What it does
- rewrites the summary toward the target role
- surfaces the most relevant Community Dreams Foundation bullets
- keeps real-work tools and lab tools distinct
- creates a cover letter when useful
- writes fit notes for interview framing
- logs the tailored package in `state/applications.csv`

## What it does not do
- invent experience
- guarantee a true rubric score of 95 in every case
- parse every possible job board format automatically

## Important
The `>=95` goal should be treated as a relevance target after tailoring, not a fabricated claim. If the job has hard blockers or big experience gaps, the package should remain honest about that.
